# Study Buddy

Paste in notes, get flashcards and a quiz generated by Claude. Built with Next.js
(App Router), Tailwind CSS, the Anthropic SDK, and Supabase for persistence.

## Setup

Requires Node.js 20+. If you're on an older Node (check with `node -v`), install
[nvm](https://github.com/nvm-sh/nvm) and run `nvm install` in this directory —
it will pick up the version pinned in `.nvmrc`.

1. Install dependencies:

   ```bash
   npm install
   ```

2. Create a free project at [supabase.com](https://supabase.com/dashboard), then
   open its SQL Editor and run the contents of [`supabase/schema.sql`](supabase/schema.sql)
   to create the `decks` table.

3. Collect your credentials and add them to a local env file:

   ```bash
   cp .env.local.example .env.local
   ```

   - `ANTHROPIC_API_KEY` — from the [Anthropic Console](https://console.anthropic.com/settings/keys)
   - `SUPABASE_URL` and `SUPABASE_SECRET_KEY` — from your Supabase project's
     **Settings -> API** page (use a secret key, `sb_secret_...`, not the publishable key)

4. Run the dev server:

   ```bash
   npm run dev
   ```

   Open [http://localhost:3000](http://localhost:3000).

## How it works

- `app/page.tsx` — the UI: a textarea for notes, a deck list, flashcard viewer, and quiz mode.
- `app/api/generate/route.ts` — calls Claude (`claude-sonnet-5`) to turn notes into
  flashcards + quiz JSON, then inserts the result into Supabase and returns the saved deck.
- `app/api/decks/route.ts` — `GET`, lists all decks.
- `app/api/decks/[id]/route.ts` — `DELETE`, removes one deck.
- `lib/supabase-server.ts` — builds a Supabase client from `SUPABASE_URL` +
  `SUPABASE_SECRET_KEY`. Only ever imported by route handlers, so the
  service role key never reaches the browser.
- `lib/api.ts` — thin `fetch` wrappers the client components call.
- `lib/types.ts` — shared `Deck` / `Flashcard` / `QuizQuestion` types.
- `supabase/schema.sql` — the `decks` table definition.

Both secrets (`ANTHROPIC_API_KEY` and the Supabase service role key) are read
from `process.env` only inside server-side route handlers — neither reaches
the browser.

## Deploying to Vercel

1. Push this project to a GitHub repo.
2. Go to [vercel.com/new](https://vercel.com/new) and import the repo.
3. In the project's Environment Variables settings, add `ANTHROPIC_API_KEY`,
   `SUPABASE_URL`, and `SUPABASE_SECRET_KEY`.
4. Deploy. Every push to the main branch redeploys automatically.

## Extending it (good next steps for a class)

- Stream the model's response instead of waiting for the full JSON payload.
- Add auth (e.g. [Clerk](https://clerk.com) or Supabase Auth) so each user has
  their own decks, and add row-level security policies scoped to `auth.uid()`.
- Add Supabase Realtime so a deck list updates live across open tabs/devices.
- Support PDF/image uploads and extract text before generating flashcards.
